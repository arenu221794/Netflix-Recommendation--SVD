# Netflix-Recommendation--SVD
# Netflix Recommendation System using SVD

## Objective
To build a recommendation system that predicts movie ratings
and recommends movies to users.

## Dataset
Netflix movie rating dataset.

## Algorithm Used
- Collaborative Filtering
- Singular Value Decomposition (SVD)

## Steps
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Create User-Movie Rating Matrix
5. Apply SVD
6. Predict Ratings
7. Generate Recommendations

## Technologies
Python
Pandas
NumPy
Scikit-learn
Surprise

## Result
The model predicts ratings for movies that the user has not
previously rated and recommends suitable movies.
